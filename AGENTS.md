# SmartMatrix: инструкции для агентов

- Документируйте изменения в Markdown. Общая инструкция запуска — `README.md`, сетевой контракт — `docs/protocol.md`.
- Консольный клиент в `src/SmartMatrix.Cli` использует .NET 8. Прошивка `firmware/SmartMatrix/SmartMatrix.ino` открывается в Arduino IDE; целевая плата — NodeMCU 1.0 (ESP8266, `esp8266:esp8266:nodemcuv2`).
- Матрица WS2812B имеет размер 16×16. В клиенте кадр идёт слева направо, сверху вниз. Порядок подключения «змейкой» учитывает только прошивка.
- Контракт JSON модели и формат передачи на плату — разные уровни. Не отправляйте необработанный ответ модели на NodeMCU.
- NodeMCU получает IP по DHCP и печатает его в Serial Monitor; пользователь вводит IP вручную.
- Не записывайте API-ключ, SSID или пароль пользователя в исходники или логи. Для Wi-Fi используйте локальный `firmware/SmartMatrix/secrets.h` на основе шаблона.
- Перед завершением изменений клиента запускайте `dotnet build SmartMatrix.sln` и `dotnet run --project tests/SmartMatrix.Tests`. Проверки на реальной плате отмечайте отдельно.
